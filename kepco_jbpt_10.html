01. Overview

HTML, CSS 웹 프레젠테이션이란?

기존처럼 파워포인트로 일일이 장표를 만드는게 아닌, AI를 활용하여 HTML, CSS, JS 코드를 생성하고 이를 활용해 발표 자료를 제작하여 웹 브라우저 환경에서 프레젠테이션을 진행하는 방식입니다.

01. Overview

웹 기반 프레젠테이션의 장점

짧은 제작시간

  • 사용자는 자료 내용만 정리하고 디자인 및 프레젠테이션 제작은 AI를 사용함으로써 기존 대비 제작시간 감소

풍부한 효과

  • CSS, JS 라이브러리 사용을 통해 다양한 전환 및 상호작용 효과 사용 가능

높은 호환성 및 범용성

  • 파워포인트 필요없이 브라우저 하나면 다 되는 호환성과 범용성
  • 파일 공유 용이

확장성, 자유도

  • 기존 파워포인트로는 구현하기 어려웠던 다양한 기능들을 슬라이드 내에서 구현 가능
Chapter 02

Workflow

AI 활용을 통한 단계별 웹 프레젠테이션 제작

02. Workflow

Step 1. 자료 정리

내용 정제 및 구조화

  • 회의록이나 발표 자료의 전체적인 내용을 텍스트나 PDF 등으로 명확하게 정리합니다.
  • 생성형 AI가 맥락을 정확하게 파악할 수 있도록 핵심 위주의 데이터를 구성 및 입력하는 단계입니다.
02. Workflow

Step 2. 프롬프트 작성 및 입력

AI 프롬프트 입력

  • 준비된 내용과 핵심 키워드를 토대로 프롬프트를 작성하여 입력합니다.
지시문 표준 예시:
~의 내용을 토대로 html, css, js를 사용하여 프레젠테이션용 n페이지 분량의 웹 페이지를 html로 작성해줘
02. Workflow

Step 3. 출력 확인 및 Feedback

결과물 확인 및 수정

  • 작성 완료된 html 페이지를 직접 확인 후, 의도와 다른 레이아웃이나 버그를 수정합니다.
  • 피드백 및 수정을 반복적으로 진행합니다.

04. Conclusion

단점

  • AI를 통해 html 코드를 빌드하는 만큼 세세한 수정이 어려우며 이미지 삽입 등 외부 자료 삽입이 번거롭습니다.
  • 사내보고서 등 서식 규격이 엄격하게 정해진 문서보다는 가볍고 유연한 발표 자료에 적합합니다.
  • Claude Opus 등 토큰 제약이 큰 인공지능 모델의 경우 무료 플랜 사용 시 사용량 제한에 도달할 수 있습니다.
04. Conclusion

장점

업무 생산성 향상

  • 짧은 제작시간 및 낮은 제작 난이도
  • 텍스트 입력만으로 고품질 장표 완성

인프라 범용성

  • 별도의 전용 프로그램 설치 없이 웹 브라우저만으로도 즉시 액세스 가능
  • PC, 모바일 등 기기를 가리지 않는 완벽한 반응형 디스플레이 구현

풍부한 시각 효과

  • HTML/CSS 고유의 인터랙티브 컴포넌트 탑재 가능
  • 라이브러리 확장을 통한 동적 무브먼트 구현
