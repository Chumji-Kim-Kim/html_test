01. Overview

HTML, CSS 웹 프레젠테이션이란?

기존처럼 파워포인트로 일일이 장표를 만드는게 아닌, AI를 활용하여 HTML, CSS, JS 코드를 생성하고 이를 활용해 발표 자료를 제작하여 웹 브라우저 환경에서 프레젠테이션을 진행하는 방식입니다.

01. Overview

웹 기반 프레젠테이션의 장점

짧은 제작시간

  • 디자인 및 프레젠테이션 제작은 AI를 사용함으로써 쉽고 빠른 초안 제작 가능

풍부한 효과

  • CSS, JS 라이브러리 사용을 통해 다양한 전환 및 상호작용 효과 사용 가능

높은 호환성 및 범용성

  • PC, 모바일 어디서나 자유로운 접속이 가능한 호환성과 범용성
  • 브라우저 기반으로 별도 전용 프로그램 없이 접근 가능

확장성, 자유도

  • javaScript를 통해 다양한 기능들을 구현 가능

02. Workflow

전체 프롬프트

첨부한 회의록과 디자인 레퍼런스를 기반으로 회의 프레젠테이션을 인트로, 내용, 아웃트로 구성으로 해서 4~5페이지 분량의 html 코드로 작성해줘

• html css js를 사용해서 코드를 작성해줘
• 폰트는 Pretendard 사용해서 Bold, Medium, Light을 내용 구성에 맞게 적절하게 사용해줘
• 강조할 부분에서는 노란색 형광펜으로 하이라이트한 효과를 넣어줘
• Fullpage.js 사용해서 한장씩 슬라이드 구조로 만들어줘 중간에 화면전환 효과도 넣어주고 터치랑 스크롤이랑 충돌 안나게 잘 넣어줘
• 흰 바탕에 깔끔하게 포인트컬러 몇 개 파스텔톤으로 해서 만들어줘
• 내용은 저거 기반으로 만들어줘, 레이아웃이나 배치, 순서는 전체 구성에 크게 어긋나지 않는 선에서 변경해도 괜찮아
• 관련 그래픽도 svg로 만들어서 적당히 깔끔하게 배치해줘
• 화면전환이나 상호작용 효과 적용 시 부드럽게 속도를 제어해줘
• 모바일에서 접속 시 레이아웃과 폰트 크기를 줄여서 깔끔하게 볼 수 있도록 반응형 디자인으로 만들어줘

04. Conclusion

단점

  • AI를 통해 html 코드를 빌드하는 만큼 세세한 수정이 어려우며 이미지 삽입 등 외부 자료 삽입이 번거롭습니다.
  • 사내보고서 등 서식 규격이 엄격하게 정해진 문서보다는 가벼운 느낌의 자료에 적합합니다.
  • Claude Opus 등 토큰 제약이 큰 인공지능 모델의 경우 무료 플랜 사용 시 사용량 제한에 도달할 수 있습니다.
04. Conclusion

장점

  • 사용자는 자료 내용만 정리하고 디자인 및 프레젠테이션 제작은 AI를 사용함으로써 업무 생산성이 대폭 향상됩니다.
  • 파워포인트 필요 없이 웹 브라우저만 있으면 작동하여 인프라 범용성과 확장성이 탁월합니다.
  • HTML 특유의 동적 오픈소스 스크립트를 자유롭게 결합하여 풍부한 시각적 상호작용 효과를 구현할 수 있습니다.
