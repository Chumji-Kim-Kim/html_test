01. Overview

HTML, CSS 웹 프레젠테이션이란?

기존처럼 파워포인트로 일일이 장표를 만드는게 아닌, AI를 활용하여 HTML, CSS, JS 코드를 생성하고 이를 활용해 발표 자료를 빌드하여 웹 브라우저 환경에서 프레젠테이션을 진행하는 방식입니다.

01. Overview

웹 기반 프레젠테이션의 장점

짧은 제작시간

  • 사용자는 자료 내용만 정리하고 디자인 및 프레젠테이션 제작은 AI를 사용함으로써 기존 대비 제작시간 감소

풍부한 효과

  • CSS, JS 라이브러리 사용을 통해 다양한 전환 및 상호작용 효과 사용 가능

높은 호환성 및 범용성

  • HTML 페이지로 프레젠테이션 자료를 제작하는 만큼 모바일, PC 어느곳에서도 접속하여 열람할 수 있는 호환성과 범용성
  • 파일 전송이 용이하다는 점도 장점

확장성, 자유도

  • 기존 파워포인트로는 구현하기 어려웠던 다양한 기능들을 슬라이드 내에서 구현 가능
Chapter 02

Workflow

AI 활용을 통한 단계별 웹 프레젠테이션 제작

02. Workflow

Step 1. 자료 정리

내용 정제 및 구조화 단계

  • 회의록이나 발표 자료의 전체적인 내용을 텍스트나 PDF 등으로 명확하게 정리합니다.
  • 생성형 AI가 맥락을 정확하게 파악할 수 있도록 핵심 위주의 데이터를 구성 및 입력하는 단계입니다.
02. Workflow

Step 2. 프롬프트 작성 및 입력

AI 명령어 설계 단계

  • 준비된 내용과 핵심 키워드를 토대로 프롬프트를 작성하여 입력합니다.
지시문 표준 예시:
~의 내용을 토대로 html, css, js를 사용하여 프레젠테이션용 n페이지 분량의 웹 페이지를 html로 작성해줘
02. Workflow

Step 3. 출력 확인 및 Feedback

코드 검증 및 반복 수정 단계

  • 작성 완료된 html 페이지를 브라우저로 직접 확인 후, 의도와 다른 레이아웃이나 버그를 수정합니다.
  • 피드백 및 부분 수정을 점진적으로 진행합니다.
02. Workflow

Step 4. 프로젝트 배포(필요시)

자세히 보기 (Click)

네트워크 접속(필요시)

  • 웹 접속 필요 시 별도 채널을 통해 프로젝트를 배포하여 인터넷으로 언제 어디서든 접속 가능하게 구현합니다.

Conclusion

트레이드 오프(장단점) 분별 및 최종 총평

04. Conclusion

단점

  • AI를 통해 html 코드를 빌드하는 만큼 세세한 수정이 어려우며 이미지 삽입 등 외부 자료 삽입이 번거로움
  • 사내보고서 등 형식이 중요한 자료보다는 좀 더 가벼운 느낌의 자료에 적합
  • 구조상 AI 활용이 필수인데 claude 등 토큰 용량이 작은 AI는 사용 중 토큰 한계 도달 가능
04. Conclusion

장점

업무 생산성 향상

  • 짧은 제작시간 및 낮은 제작 난이도

인프라 범용성

  • 플랫폼 제한이 없는 높은 호환성 및 범용성 보장

풍부한 시각적 이펙트

  • html 특유의 다양한 효과 및 기능 구현 가능

프로젝트 배포 상세 내용

별도 채널(예: GitHub Pages, Netlify, Vercel 등 웹 호스팅 서비스)을 통해 빌드된 HTML 프로젝트를 배포하고 URL 주소를 공유하여 실시간으로 접근 할 수 있습니다.

디자인 키워드 및 UI 세부 가이드

Neuromorphism, Flat, Glassmorphism 같은 인터페이스 디자인 방법론을 지시하여 구조물의 시각적 입체감과 투명 가독성을 제어하는 세부 조건 명시 가이드입니다.

JS 라이브러리 선언 상세 기법

fullpage.js를 통한 터치 친화형 안내화면 이동 제어 기법, Three.js 기반의 3D 렌더링 컨텍스트 스크립트 결합, Chart.js의 동적 데이터 배열 매핑 기술 세부 사양 설명 영역입니다.

간단한 회의 진행 실증 분석

주니어보드 월간 정기회의 도입 시 기존 PPT 포맷 생산 워크로드 대비 시간 축소 지표 및 단순 텍스트 원안 입력의 실무적 편의성 검증 데이터 기록 영역입니다.

HTML 기술 고도화 연계 사례 사양

변전소 주위환경 시뮬레이션 인터페이스 연동 등 전통적 문서 도구 내부에서는 연출이 불가능했던 실시간 돔(DOM) 객체 제어 및 기능 통합의 구조학적 설명 영역입니다.
